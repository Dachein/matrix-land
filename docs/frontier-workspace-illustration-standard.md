# Frontier Workspace 默认配图规范

2026-10-30。来源：用户提供的五张照片/手绘对照图，明确要求参考每张右侧的绘画，并描述为“有点东方现代的”。这是一项**插画规范，不是 UI 配色方案**。

## 视觉语言：现代东方 · 纸墨淡彩

- 主体以简练的钢笔或墨线表现，线条有自然轻重、断续和少量干笔感；保留动态和轮廓，不追求照片式细节。
- 以透明水彩局部铺色，保留纸面与肌理，不把轮廓均匀填满；明暗通过少量灰阶和彩色笔触表达。
- 大面积留白，空间轻盈。纸张质感细腻、克制，不使用重度复古污渍或整页高噪点。
- 人物自然、现代，面部适度省略。场景取自阅读、交流、工作、思考、协作等真实活动；不默认加入古装、山水、印章或书法装饰。
- 画面主题、人物和姿态原创。参考图用于风格判断，不直接复制其人物、摄影、水印、签名或社交平台 UI。

## 适用与边界

欢迎页、初始化引导、空状态、帮助说明、内容封面和宣传图默认采用上述风格。插画是情境和情感表达，不承担唯一的状态提示。

导航图标、操作按钮、表单边界、图表和权限状态仍采用统一组件规范；不把手绘笔触套到功能控件。插画局部用色可与当前选定品牌方案呼应，但不能反过来改写主色、配套色、正文或系统状态色。

空状态尺寸较小时使用单主体、少细节；欢迎页可使用多人协作场景，但保持文字区域留白。重要信息以真实文本提供，禁止烘焙进插画；装饰图使用空 alt，承担内容含义的插画提供描述性 alt。

## 默认创作描述

“现代东方气质的钢笔淡彩插画。自然且有轻重变化的墨线，局部透明水彩，细腻纸张肌理与大量留白。以简练轮廓表达现代人物的动作和关系，面部细节克制，画面轻盈、安静、有生活感。围绕指定的工作场景原创构图，无文字、水印或签名。”

每次创作补充具体场景、横竖比例、文字留白方向和用途；不能只重复风格词。验收应检查动作可读性、缩小后的识别度、裁切、与页面背景的衔接，以及是否让内容成为主角。

本次仅建立规范；尚未生成或替换正式产品插画。
