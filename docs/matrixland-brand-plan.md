# Matrix Land SI 品牌升级规划

本轮将 Frontier Workspace 的产品品牌与原 Cookbook 的出版品牌统一到 Matrix Land SI。产品能力、模块职责、数据模型和部署方式保持不变。品牌定义、网站入口与阅读版同步更新；后续工程迁移以兼容现有实例为前提。

## 1 名字的依据

1999 年 11 月 6 日，沃卓斯基导演在华纳举办的 Matrix Virtual Theatre 在线问答中，被问及 Matrix 是否指细胞中的线粒体基质。回答强调名字具有多重含义，并明确提及数学上的矩阵和女性子宫。可核查的记录来自原华纳页面的 PDF 留存，第 6 页：其中有短句 “the mathematical definition” 和 “a woman's womb”。不能把这段回答扩大为“导演只用子宫含义命名”，也没有依据把线粒体解释认定为唯一来源。[原访谈 PDF 留存](https://digitalair.com/pdfs/1999.11.06_Wachowskis_Transcript.pdf)、[文字转录](https://www.matrixfans.net/movies/the-matrix/wachowski-brothers-chat-transcript/)

Merriam-Webster 将 matrix 的词源追溯到拉丁语 matr-、mater，并说明其现代义包括事物从中产生、发展或成形的环境。因此，品牌采用“让事物形成的母体与结构”这一解释；“孕育创造的共同空间”是我们自己的品牌延伸。[Merriam-Webster 词源与释义](https://www.merriam-webster.com/dictionary/matrix)

| 组成 | 品牌解释 | 对应现有产品 |
| --- | --- | --- |
| Matrix | 事物得以形成的母体；把要素连接起来的结构 | 知识、身份、工具与模型共同构成创作基础 |
| Land | 可以进入、建设、协作和拥有的空间 | 团队以自己的账号、域名和配置独立部署 |
| SI | Superintelligence 的长期愿景 | 从当下人与 AI 的具体协作出发；不作已实现超智能的能力声明 |

`.si` 的注册局含义是斯洛文尼亚国家和地区顶级域。将 SI 解释为 Superintelligence 是品牌选择，与域名注册属性不同。[IANA .si 记录](https://www.iana.org/domains/root/db/si.html)

电影提供名称的文化联想；品牌视觉与产品叙事采用自己的创作语言，不暗示电影官方关联。无需使用绿色代码雨、药丸、角色肖像等电影符号。

## 2 名称与定位

完整品牌统一写作 **Matrix Land SI**。日常简称 **Matrix Land**；英文网址、资源 slug 使用 `matrixland`。不在公开界面交替使用 Matrixland、Matrix Land SI Workspace 等多种主名称。

定位句：**一个可独立部署的开源 AI 工作区，让团队把自己的工作方式构建出来。**

主张：**创造，自成世界。**

辅助表达：**连接知识、工具与 AI。共同创造，各自拥有。**

品牌故事：每一个组织都有自己的知识、判断和做事的方法。Matrix Land SI 为这些要素提供一个可以共同工作的地方：人带来问题与方向，知识提供依据，工具承接行动，AI 参与推进。组织可以建立自己的实例，持续改造工具，让一次解决问题的办法成为下一次工作的起点。

| 使用场景 | 统一名称 | 说明 |
| --- | --- | --- |
| 官网和产品介绍 | Matrix Land SI | 官方域名 `matrixland.si` |
| 实际软件 | Matrix Land SI；必要时附“AI 工作区” | Workspace 是产品类别，不再是第二个主品牌 |
| 实践手册 | Matrix Land SI Cookbook | 短文中可称 Cookbook |
| 企业实例 | 企业自选名称与 Logo | 品牌升级不覆盖企业已有配置 |
| 现有模块 | Mate、知识库、工作室、应用、Skills、连接等 | 延续功能命名，不创建新的能力层级 |
| 作者与许可证 | 保留原始署名和许可证 | 商业展示名称变化不重写历史权利归属 |

SI 在 Logo 中可作为较小的独立标记，文字阅读仍为 Matrix Land SI。避免把 SI 设计成付费版、产品版本号或新模块标记。

## 3 文案与视觉系统

| 内容 | 中文 | English | 日本語 |
| --- | --- | --- | --- |
| 主张 | 创造，自成世界。 | Make a world of your own. | 創造から、自分たちの世界を。 |
| 辅助表达 | 共同创造，各自拥有。 | Built together. Owned by you. | 共につくり、自分たちで持つ。 |
| 描述 | 连接知识、工具与 AI，把你的工作方式构建出来。 | Connect knowledge, tools and AI. Build your own way of working. | 知識、ツール、AI をつなぎ、自分たちの働き方をつくる。 |

中文直接说行动和结果，英语与日语按各自阅读习惯表达。术语可解释，能力不夸大；上线状态、案例效果和验收结果保持原有事实口径。

颜色延续官网：纸白 `#f3f0e7`、墨黑 `#24251f`、陶橙 `#c96838`。产品现有 palette ID 和八组可选配色保持不变。先锋感来自大字号、硬边线、非对称排版、坐标与轨道的几何关系，手绘线保留人的参与感。

字标采用 MATRIX LAND 与较小 SI，图形语言围绕“结构中生成新的组合”。官网适合强烈的展示字；Cookbook 正文保留长文阅读的行距、宽度和原图。封面升级不会要求读者重新学习翻页和目录。

## 4 Cookbook 的品牌升级

采用电脑中独立的 `fargo-ai-cookbook` 0.1.31 源码。原入口 HTML 依赖 React、章节代码、JSON 和图片，因此迁移完整的必要阅读资源；原目录保持原样。

| 原有内容 | 本轮处理 |
| --- | --- |
| 从 Excel 到 SSOT | 保留原文、论述、示意图与出处 |
| Philosophy | 更新品牌前缀；继续保留数据优先、AI 计算优先、业务优先、权限优先 |
| 平台使用 | 更新品牌称谓，保留九个模块与原有说明 |
| AI Adoption Roadmap | 保留六步方法、周会案例、任务编辑、保存与导出 |
| 阅读指南与共同创作 | 保留阅读路径、术语、贡献方式；加一段品牌说明 |
| 封面和导航 | 新字标、新封面、官网返回入口与全书目录 |
| 本书的托管说明 | 改为 Matrix Land SI 官网静态阅读版，避免沿用旧托管事实 |

不把 SSOT、Ontology、Harness 重新包装成新功能，也不增加“数据最终态”承诺。它们继续服务于原文对共同事实、业务对象、运行约束的解释。

官网主站支持中文、英文、法语、西班牙语、阿拉伯语和日语，阿拉伯语采用从右到左排版。Blog 仅支持中文与英文；Cookbook 保留中文全文。未来翻译需要分别验收正文、图注、图内文字与交互，不因主站有语言切换就宣称全书三语完成。

Cookbook 代码存放于 `sites/frontier-website/cookbook-src`，统一构建到 `dist/cookbook/`，正式入口 `https://matrixland.si/cookbook/`。阅读器不引入新后端、收费服务或共享数据库。

## 6 迁移顺序与验收

| 阶段 | 交付 | 完成标准 |
| --- | --- | --- |
| A 品牌基线 | 名称、故事、主张、术语、三语表达 | 对外只保留一个主品牌；来源与品牌诠释分开 |
| B 官网与 Cookbook | 官网三语更新、阅读器迁入、新封面、互链 | 全站可访问，章节跳转/图片/任务保存正常，无旧品牌宣传引用 |
| C 软件显示层 | 默认安装品牌、README、规范、登录页与通知模板检查 | 新实例显示新品牌；企业自定义品牌保留；不会修改身份或权限 |
| D 发行资料 | 源码归档、版本说明、公开仓库与安装材料 | 版本与归档一致，历史署名保留，真实部署状态准确 |

本轮更新品牌示例配置与核心产品规范。软件所有默认值和模板的全面扫描属于 C 阶段的后续验收；本轮不批量替换 API、包名、命令、Cookie、数据库或云资源 ID。

工程名称兼容策略：保留 `frontier-workspace` CLI、现有 npm 包名、`fw-*` 资源前缀、`WORKSPACE_*` 环境变量、源目录和服务 ID。现有安装文档中的命令继续可用。今后若确需改名，先设计兼容策略并另发版本。

历史站点的跳转、旧公开链接的迁移与公共仓库正式发布独立记录，不删除旧项目或用户本地笔记。更新后的源码归档应重新生成；旧归档不能作为本轮品牌发布的源码证明。
